# MCP Инструменты

## 1. `search_documents_tool`

**Семантический поиск документов**

| Параметр | Обязательный | Тип | По умолчанию | Описание |
|----------|-------------|-----|--------------|----------|
| `query_text` | ✅ | string | — | Текст запроса |
| `collection_name` | ❌ | string | — | Коллекция Qdrant |
| `limit` | ❌ | integer | 10 | Количество результатов (1-100) |
| `filter` | ❌ | object | — | Фильтр по payload |
| `include_old_versions` | ❌ | boolean | false | Старые версии |
| `max_text_length` | ❌ | integer | 0 | Максимальная длина текста в результате (0 = без ограничений) |
| `group` | ❌ | boolean | true | Группировать результаты по category_path |

**Описание параметра `max_text_length`:**
- Если `0` (по умолчанию), текст возвращается в полном объеме
- Если положительное число, текст будет обрезан до указанной длины
- При обрезании добавляется суффикс `...`

**Описание параметра `group`:**
- Если `true` (по умолчанию), результаты группируются по category_path (один результат на категорию)
- Если `false`, возвращаются отдельные чанки (один результат на чанк)

**Пример:** `{"query_text": "настройка векторного поиска", "collection_name": "documents", "limit": 5}`

**Пример с ограничением длины текста:** `{"query_text": "настройка", "collection_name": "documents", "max_text_length": 1500}`

**Пример с отключенными группировкой (отдельные чанки):** `{"query_text": "настройка", "collection_name": "documents", "group": false}`

## 2. `search_categories_tool`

**Поиск категорий по запросу (результаты всегда сгруппированы по коллекциям)**

| Параметр | Обязательный | Тип | По умолчанию | Описание |
|----------|-------------|-----|--------------|----------|
| `query_text` | ✅ | string | — | Текст запроса |
| `limit` | ❌ | integer | 10 | Количество категорий (1-50) |

**Особенности:**
- Всегда возвращает результаты, сгруппированные по коллекциям
- Для каждой коллекции показывает категории с релевантными путями и их семантическим score
- Коллекции без релевантных категорий не включаются в результат

**Пример ответа:**
```
Релевантные категории:

[Коллекция: syntx_1C]
  - 1С / Общие объекты / DOM / ДокументDOM (score: 0.538)
  - 1С / Общие объекты / Web-сервисы / WSПараметр / Свойства / Документация (score: 0.523)

[Коллекция: 1c_integration]
  - Интеграция / API / Методы / СоздатьЗапрос (score: 0.485)
```

**Пример вызова:** `{"query_text": "документация API", "limit": 10}`

## 3. `get_category_hierarchy_tool`

| Параметр | Обязательный | Тип | По умолчанию | Описание |
|----------|-------------|-----|--------------|----------|
| `collection_name` | ❌ | string | — | Коллекция Qdrant. Если не указано, возвращает категории для всех коллекций. |
| `depth` | ❌ | integer | 1 | Количество уровней для получения (0 - только список коллекций без категорий, 1-10 - иерархия категорий). |
| `categories` | ❌ | object | — | Массив полных путей категорий. Если указаны, возвращает только коллекции с этими категориями. |

**Описание параметра `depth`:**
- Если `0`, возвращается только список коллекций без категорий
- Если `1-10`, возвращается иерархия категорий на указанное количество уровней
- Максимальное значение: 10

**Описание параметра `categories`:**
- Если указаны, возвращаются только коллекции, содержащие эти категории
- Путь категории может быть строкой вида "Категория / Подкатегория"

**Пример (все коллекции, глубина 1):** `{"depth": 1}`

**Пример (конкретная коллекция, глубина 2):** `{"collection_name": "documents", "depth": 2}`

**Пример (с фильтром по категориям):** `{"depth": 2, "categories": ["Документация / API", "Документация / руководства"]}`

**Пример ответа:**
```
Иерархия категорий:

### Коллекция: syntx_1C
- Документация / API (27273 чанков)

### Коллекция: 1c_integration
- Интеграция / API (931 чанков)
```

## Методы JSON-RPC 2.0

| Метод | Описание |
|-------|----------|
| `initialize` | Инициализация клиента |
| `ping` | Проверка доступности |
| `tools/list` | Список инструментов |
| `tools/call` | Вызов инструмента |

## Аутентификация
- **URL:** `http://localhost:8000/mcp`
- **Method:** POST
- **Auth:** Basic (mcp_user:mcp_pass)
- **Content-Type:** application/json
