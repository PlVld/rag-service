Загружает несколько файлов одновременно.

**Параметры:**
- `files` – массив файлов (поддерживаются `.txt`, `.pdf`, `.docx`, `.doc`, `.html`, `.htm`, `.md`)
- `collection_name` – имя коллекции в Qdrant
- `skip_if_exists` – пропускать уже существующие файлы (по умолчанию `false`); игнорируется для файлов, у которых задано перемещение в новую категорию
- `metadata` – JSON-массив объектов, каждый объект соответствует файлу в том же порядке.

**Извлечение изображений:**
Для файлов PDF, DOCX и HTML картинки автоматически извлекаются и становятся доступны по публичным URL:
```
/media/{source_id}/{doc_hash[:16]}/images/{filename}
```
Ссылки подставляются в Markdown-текст автоматически. Загрузка картинок не требует токена аутентификации.

**Формат metadata:**

```json
[
  {"source_format": "pdf", "category_path": ["Категория1"]},
  {"source_format": "txt", "category_path": ["Категория2"], "new_category_path": ["Категория3"]}
]
```

Каждый объект может содержать поля:
- `file_path` (опц.) – путь к файлу (для метаданных)
- `source_format` (опц.) – формат (`pdf`, `text`, ...)
- `category_path` (опц.) – категория поиска (массив категорий); `source_id` документа вычисляется сервером из неё и имени файла
- `new_category_path` (опц.) – новая категория (присвоение): перемещает найденный документ в другую категорию

**Результат:** массив объектов с информацией о каждом файле (`status`, `version`, `chunk_ids`, при перемещении — `prev_source_ids` и т.д.).
