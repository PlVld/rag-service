Возвращает сгруппированный текст чанков без семантического поиска.

Чанки отбираются по коллекции, категориям и списку документов, затем группируются
по паре «документ + категория». Внутри группы текст склеивается в порядке `chunk_index`.

**Параметры запроса:**
- `collection_name` — имя коллекции Qdrant. Если не указано, выборка выполняется по всем коллекциям, кроме служебной коллекции категорий.
- `categories` — массив путей категорий. Учитывается точное совпадение и вложенность (`A / B` включает `A / B / C`).
- `documents` — массив идентификаторов документов (`source_id`).
- `include_old_versions` — включать старые версии (по умолчанию `false`, только актуальные).
- `max_text_length` — максимальная длина текста каждой группы (`0` = без ограничений).
- `limit` — максимальное количество групп «документ + категория» (1–1000, по умолчанию 20).

**Особенности:**
- Не требует `query_text` и не использует эмбеддинги — выборка детерминированная.
- Фильтр по категориям выполняется в Qdrant по индексируемым полям `category_levelN`,
  фильтр по документам — по `source_id`.
- Текст читается в две фазы: сначала только метаданные чанков, затем `raw_text`
  лишь для групп, попавших в ответ после применения `limit`.
- Фильтр по категориям включает вложенные категории.
- Если `documents` не указан, возвращаются все документы, подходящие под остальные фильтры.
- Группы сортируются по коллекции, `source_id`, номеру первого чанка и категории.

**Производительность:** время ответа пропорционально объёму выборки. Без
`categories` и `documents` выполняется полный перебор коллекции — для больших
коллекций это заметно медленнее, поэтому такие фильтры рекомендуется указывать.

**Пример запроса:**
```json
{
  "collection_name": "documents",
  "categories": ["Документация / API"],
  "documents": ["6ba7b810-9dad-11d1-80b4-00c04fd430c8"],
  "include_old_versions": false,
  "max_text_length": 0,
  "limit": 20
}
```

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "source_id": "6ba7b810-9dad-11d1-80b4-00c04fd430c8",
        "collection_name": "documents",
        "category_path": "Документация / API",
        "version": 1,
        "first_chunk_index": 0,
        "last_chunk_index": 2,
        "chunk_indices": [0, 1, 2],
        "chunk_count": 3,
        "total_chunks": 5,
        "original_filename": "api_guide.md",
        "document": "Текст первого чанка\nТекст второго чанка\nТекст третьего чанка"
      }
    ]
  },
  "error": null,
  "meta": {"timestamp": "2025-01-01T00:00:00Z", "version": "1.0.0"}
}
```
