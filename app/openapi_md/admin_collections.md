Возвращает список всех коллекций (кроме `categories`) с уникальными категориями верхнего уровня (уровень 0).

**Формат ответа:**
- `name`: имя коллекции
- `categories`: массив полных путей категорий (уровни 0 и 1)

**Пример:**

```json
{"collections": [{"name": "documents", "categories": ["Docs", "Docs / API"]}]}
```
