Выполняет семантический поиск и группирует результаты по документам и их версиям.

**Параметры запроса (в формате form-data или JSON body):**
- `query_text` — текст запроса для поиска (обязательно при передаче через form-data)
- `collection_name` — имя коллекции в Qdrant. Если не указано, поиск выполняется по всем коллекциям, кроме служебной коллекции категорий.
- `limit` — максимальное количество результатов (1–1000, по умолчанию 10)
- `filter` — условия фильтрации по полям payload (JSON-объект, передается как строка или объект). Параметр может называться `filter` или `filter_param` в зависимости от способа передачи.
- `include_old_versions` — включать ли старые версии документов (по умолчанию false)
- `max_text_length` — максимальная длина текста в результате (0 = без ограничений, по умолчанию 0)

**Особенности:**
- Группирует найденные чанки по `category_path` и `source_id`
- Для каждой категории возвращает целостный фрагмент с соседними чанками
- Поддерживает RRF-ранжирование с учётом категорий
- **Пересчитывает score чанков через косинусное сходство с вектором запроса** для более точного ранжирования (reranking)
- Возвращает историю версий документа
- Если `max_text_length > 0`, текст будет обрезан до указанной длины

**Алгоритм работы:**
1. Выполняется RRF-поиск в указанных коллекциях
2. Результаты объединяются и сортируются по RRF score
3. **Чанки пересортировываются на основе косинусного сходства с вектором запроса** (reranking)
4. Результаты группируются по category_path
5. Для каждой категории строится полный контекст с соседними чанками

Используется, когда нужен целостный контекст документа, а не отдельные фрагменты.

**Преимущества reranking:**
- Более точное ранжирование (настоящее косинусное сходство вместо RRF)
- Возможность сравнения чанков из разных коллекций
- Улучшение качества результатов при поиске по нескольким коллекциям

**Пример запроса (JSON body):**
```json
{
  "query_text": "Как настроить API?",
  "limit": 10,
  "filter": {"source_format": "markdown"},
  "include_old_versions": false
}
```

**Пример запроса (form-data):**
```
query_text=Как настроить API?
limit=10
filter={"source_format": "markdown"}
include_old_versions=false
```

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "source_id": "uuid",
        "category_path": "Документация / API",
        "original_filename": "api_guide.md",
        "content_type": "markdown",
        "collection_name": "documents",
        "score": 0.87,
        "chunk_score": 0.82,
        "versions": [
          {
            "version": 1,
            "raw_text": "Текст документа...",
            "is_latest": true,
            "total_chunks": 3,
            "first_chunk_index": 0,
            "last_chunk_index": 2
          }
        ]
      }
    ]
  }
}
```
