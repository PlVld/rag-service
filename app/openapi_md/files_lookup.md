Ищет актуальные (`is_latest`) документы по SHA256-хешу файла — тот же алгоритм, что используется при загрузке.

Клиент может:
- передать сам файл (`file`) — сервер вычислит хеш сам (удобно, если нет возможности считать SHA256 на клиенте);
- передать готовый `doc_hash` — тогда файл не нужен.

Возвращает вычисленный хеш и список совпадений по коллекции. Каждое совпадение содержит `source_id`, `version`, `original_filename` и `category_path` — категории уровня документа (без иерархии заголовков).

Полученный `category_path` используется при загрузке файла как категория поиска; если пользователь выбрал другую цепочку или ввёл новую — она передаётся в `new_category_path`, и документ перемещается.

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "doc_hash": "9f86d081884c7d65...",
    "matches": [
      {"source_id": "6ba7b810-9dad-11d1-80b4-00c04fd430c8", "category_path": ["Документация", "API"], "version": 2, "original_filename": "guide.pdf"},
      {"source_id": "0f14d0ab-9605-4a62-a9e4-5ed26688389b", "category_path": ["Руководства"], "version": 1, "original_filename": "guide.pdf"}
    ]
  }
}
```

Несколько совпадений означают, что файл с таким содержимым уже лежит в нескольких категориях.
