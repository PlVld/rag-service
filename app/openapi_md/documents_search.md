Выполняет семантический поиск по тексту в документах.

**Параметры запроса (в формате form-data или JSON body):**
- `query_text` — текст запроса для поиска (обязательно при передаче через form-data)
- `collection_name` — имя коллекции в Qdrant. Если не указано, поиск выполняется по всем коллекциям, кроме служебной коллекции категорий.
- `limit` — максимальное количество результатов (1–1000, по умолчанию 10)
- `min_score` — минимальный score результата (0–1, по умолчанию 0.55). Результаты с меньшим косинусным сходством отбрасываются; отсечение выполняется в Qdrant и повторно после reranking. `null` — тоже значение по умолчанию, `0` отключает порог
- `exact_phrases` — до 10 ключевых слов/фраз для точного (лексического) поиска по `raw_text` (по умолчанию не задан). Совпадения добавляются к семантическим, идут первыми и не отбрасываются `min_score`
- `phrase_mode` — режим точного поиска: `any` (по умолчанию) — достаточно любой фразы, `all` — должны встретиться все
- `filter` — условия фильтрации по полям payload (JSON-объект, передается как строка или объект). Параметр может называться `filter` или `filter_param` в зависимости от способа передачи.
- `include_old_versions` — включать ли старые версии документов (по умолчанию false)
- `max_text_length` — максимальная длина текста в результате (0 = без ограничений, по умолчанию 0)
- `group` — группировать ли результаты по category_path (true по умолчанию). Если true, возвращает сгруппированные документы. Если false, возвращает отдельные чанки.

**Особенности:**
- Использует векторное сопоставление для поиска релевантных чанков
- Поддерживает фильтрацию по произвольным полям через `filter`
- При наличии релевантных категорий применяется RRF-ранжирование (Reciprocal Rank Fusion)
- **Пересчитывает score чанков через косинусное сходство с вектором запроса** для более точного ранжирования (reranking)
- По умолчанию возвращает только актуальные версии (`is_latest=true`)
- Если `max_text_length > 0`, текст будет обрезан до указанной длины
- По умолчанию результаты группируются по category_path (`group=true`)

**Алгоритм работы:**
1. Выполняется RRF-поиск в указанной коллекции (или всех коллекциях, если `collection_name` не указан)
2. Если задан `exact_phrases`, параллельно выполняется точный поиск по полнотекстовому
   индексу `raw_text`: слова ищутся целыми токенами без учёта регистра, фразы —
   как последовательность токенов. Найденные точки объединяются с семантическими
   (дубликаты схлопываются), помечаются `_exact_match`/`_matched_phrases`
3. **Чанки пересортировываются на основе косинусного сходства с вектором запроса** (reranking)
4. Отсечение по `min_score`; точные совпадения сохраняются независимо от score
5. При наличии `exact_phrases` результат сортируется exact-first, затем по числу
   совпавших фраз и score

**Точный поиск и индекс:** для `exact_phrases` на коллекции нужен полнотекстовый
индекс `raw_text` (создаётся скриптом `scripts/create_text_index.py` для существующих
коллекций и автоматически при инициализации новых). Без индекса семантика условий
`MatchText`/`MatchPhrase` зависит от версии Qdrant, поэтому такие коллекции
следует проиндексировать.

**Преимущества reranking:**
- Более точное ранжирование (настоящее косинусное сходство вместо RRF)
- Возможность сравнения чанков из разных коллекций
- Улучшение качества результатов при поиске по нескольким коллекциям

Возвращает список найденных чанков с их `id`, `score` и исходным текстом.

**Пример запроса (JSON body):**
```json
{
  "query_text": "Как настроить API?",
  "collection_name": "documents_prod",
  "limit": 10,
  "filter": {"is_latest": true},
  "include_old_versions": false,
  "group": true
}
```

**Пример запроса с точным поиском (JSON body):**
```json
{
  "query_text": "перенос данных между базами",
  "collection_name": "1c_integration",
  "limit": 5,
  "exact_phrases": ["TransferChunk", "Checksum"],
  "phrase_mode": "all",
  "min_score": 0.5
}
```

**Пример запроса (form-data):**
```
query_text=Как настроить API?
collection_name=documents_prod
limit=10
filter={"is_latest": true}
include_old_versions=false
group=true
```

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "score": 0.95,
        "document": "Текст чанка...",
        "collection_name": "documents_prod",
        "category_path": "Документация / API",
        "source_id": "uuid",
        "first_chunk_index": 2,
        "last_chunk_index": 4,
        "total_chunks": 10,
        "exact_match": true,
        "matched_phrases": ["TransferChunk"]
      }
    ]
  }
}
```

Поля `exact_match` и `matched_phrases` присутствуют только у результатов,
связанных с точным поиском (при `group=true` — если хотя бы один чанк группы
содержит искомую фразу).
