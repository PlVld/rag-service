Выполняет семантический поиск по иерархии категорий.

**Параметры запроса (в JSON body):**
- `query_text` — текст запроса для поиска (обязательно)
- `limit` — максимальное количество результатов (1–100, по умолчанию 10)
- `grouped` — если `true`, возвращает категории, сгруппированные по коллекциям (по умолчанию `false`)
- `fields` — список полей для возврата (опционально). Если не указан, возвращаются только `path` и `score`.

**Доступные поля для `fields`:**
- `path` — полный путь категории
- `score` — релевантность категории
- `id` — идентификатор категории
- `category_name` — название категории
- `categories` — список категорий в пути
- `category_level` — уровень вложенности
- `category_id` — идентификатор категории
- `levels.category_level0`, `levels.category_level1`, ... — уровни категорий
- `id_levels.category_id_level0`, `id_levels.category_id_level1`, ... — идентификаторы уровней

**Формат запроса (минимальный):**
```json
{
  "query_text": "документация API",
  "limit": 10
}
```

**Формат ответа (по умолчанию - только path и score):**
```json
{
  "results": [
    {"path": "Документация / API", "score": 0.95},
    {"path": "Документация / Настройка", "score": 0.87}
  ]
}
```

**Формат запроса (с полями):**
```json
{
  "query_text": "документация API",
  "limit": 10,
  "fields": ["path", "score", "category_name"]
}
```

**Формат ответа (с полями):**
```json
{
  "results": [
    {
      "path": "Документация / API",
      "score": 0.95,
      "category_name": "API"
    }
  ]
}
```

**Группировка по коллекциям:**
Когда параметр `grouped=true`, результат возвращается в формате:
```json
{
  "results": {
    "documents": [
      {"path": "Документация / API", "score": 0.95}
    ],
    "documents_archive": [
      {"path": "Архив / Справочник", "score": 0.75}
    ]
  }
}
```

**Особенности:**
- Использует векторное сопоставление для поиска релевантных категорий
- Возвращает полный путь категории (`category_path`) и уровень вложенности
- **По умолчанию возвращает только `path` и `score`** для оптимизации производительности
- При необходимости можно получить полную информацию, указав поля в `fields`
- Результаты можно сгруппировать по коллекциям с помощью параметра `grouped`

Используется для улучшения поиска документов через RRF-ранжирование, учитывая релевантность категорий.
